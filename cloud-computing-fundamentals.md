# Cloud Computing Fundamentals

## Introduction
Cloud computing is the delivery of computing services such as servers, storage, databases, networking, software, analytics, and intelligence over the internet (the cloud). Instead of owning physical hardware, users can access resources on demand from cloud providers.

## Key Characteristics
- On-demand self-service: Resources can be provisioned automatically without manual intervention.
- Broad network access: Services are available over the internet from different devices.
- Resource pooling: Providers share computing resources among multiple customers.
- Rapid elasticity: Resources can scale quickly based on demand.
- Measured service: Usage is monitored, controlled, and billed.

## Cloud Service Models
### 1. Infrastructure as a Service (IaaS)
Provides virtualized computing resources such as virtual machines, storage, and networks.

Examples:
- Azure Virtual Machines
- Amazon EC2
- Google Compute Engine

### 2. Platform as a Service (PaaS)
Provides a managed platform for developing, running, and managing applications without managing underlying infrastructure.

Examples:
- Azure App Service
- Google App Engine
- Heroku

### 3. Software as a Service (SaaS)
Delivers fully managed software applications over the internet.

Examples:
- Microsoft 365
- Gmail
- Salesforce

## Cloud Deployment Models
### Public Cloud
Cloud services are provided by third-party providers over the public internet.

### Private Cloud
Dedicated cloud infrastructure operated for a single organization.

### Hybrid Cloud
A combination of public and private clouds, allowing data and applications to move between them.

## Benefits of Cloud Computing
- Cost savings: Reduces need for upfront hardware investment.
- Scalability: Easily adjust resources as demand changes.
- Flexibility: Supports different workloads and environments.
- Reliability: Providers often use redundancy and backup systems.
- Security: Cloud providers implement security controls, monitoring, and compliance features.

## Common Cloud Concepts
- Virtualization: Creation of virtual machines and networks from physical hardware.
- Containers: Lightweight, portable units for running applications.
- Serverless computing: Run code without managing servers.
- Load balancing: Distributes traffic across resources for reliability and performance.
- Autoscaling: Automatically adds or removes resources based on demand.

## Azure Examples
Microsoft Azure offers cloud services such as:
- Azure Virtual Machines for compute
- Azure Storage for file and object storage
- Azure SQL Database for managed databases
- Azure App Service for web applications
- Azure Functions for serverless computing

## Challenges
- Security and compliance concerns
- Vendor lock-in
- Downtime or network dependency
- Cost management if resources are not monitored properly

## Summary
Cloud computing enables businesses and individuals to access scalable, flexible, and cost-effective computing resources over the internet. Understanding the core service and deployment models is essential for working with modern cloud platforms like Azure.
